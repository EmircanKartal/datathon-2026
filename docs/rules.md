# Competition Rules — BTK Akademi Datathon 2026

## Critical Constraints

| Rule | Detail |
|------|--------|
| BTK Registration | Must register at [btkakademi.gov.tr](https://btkakademi.gov.tr) before deadline |
| Kaggle accounts | One account per person — no multi-account submissions |
| Daily submissions | **Maximum 5/day** |
| Final selection | Choose **2 submissions** as final entries |
| Code sharing | Top-10 teams **must** share notebooks/code |
| Private sharing | No data/solution sharing between teams outside Kaggle |
| Previous winners | 2021–2025 Datathon top-3 are **ineligible** |

## Leaderboard Structure

- **Public LB:** 60% of test data — visible during competition
- **Private LB:** 40% of test data — determines final rankings
- Top-10 is determined by Private LB, then subject to BTK jury review

## Tie-Breaking

In case of equal scores on the Private LB, the submission entered **first** wins. Submit strong solutions early.

## Code Requirements

- All code must be original work
- Open source libraries must use OSI-approved licenses
- No private code sharing between separate teams
- Public sharing on Kaggle forums/notebooks is permitted

## Prize Path

1. Top-10 by Private LB → BTK pre-screening
2. Pass screening → Present to jury (5 min + 3 min Q&A, online)
3. Top-3 determined by jury → Award ceremony at BTK Data Science Summit
